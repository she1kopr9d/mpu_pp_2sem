# Задание 1.

## Формулировка задания

**Напишите программу, которая с помощью стека проверяет правильность расстановки
парных скобок в каждой введенной с клавиатуры строке. Модифицировать класс Stack
можно только в части типов данных. Строка должна изучаться посимвольно, за один
проход.**

Примеры:
• cc[cc] – правильно;
• cc{cc[cc]cc}cc – правильно;
• cc{cc[cc}cc]cc – неправильно;
• {cc(cc]cc}cc – неправильно;
• cc[cc{cc}cc]cc} – неправильно;
• cc{cc(cc) – неправильно.

Приведите примеры входных данных, на которых проверяли работоспособность программы
(не менее десяти).
Работа над решением должна сопровождаться полноценным ведением локального
репозитория.

ПОМЕТКА: Допустимо изменение типа хранимых в стеке данных.

Задания
