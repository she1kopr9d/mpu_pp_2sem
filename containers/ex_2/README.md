# Задание 2. Реализация дека

## Формулировка задания

Создайте непрерывную реализацию ограниченной двусторонней очереди целых чисел на
базе вектора (класс Deq нужно вывести из класса Queue):

Дополнительно: создайте дек из пяти элементов и последовательно выведите его элементы в
прямом и обратном направлениях (без модификации класса Deq).
Спецификации методов в классе Deq (также потребуются вспомогательные методы forward и
backward):

```java
// Пуст ли дек? [x]
boolean empty(); 
// Сделать дек пустым. [x]
void clear();
// Добавить число в начало дека. [x]
void pushFront(int val);
// Добавить число в конец дека. [x]
void pushBack(int val);
// Удалить первый элемент дека. [x]
int popFront() throws Exception;
// Удалить последний элемент дека. [x]
int popBack() throws Exception;
// Получить первый элемент дека (не удаляя его). [x]
int front() throws Exception;
// Получить последний элемент дека (не удаляя его). [x]
int back() throws Exception;
```

Приведите примеры входных данных, на которых проверяли работоспособность программы
(не менее десяти).
Работа над решением должна сопровождаться полноценным ведением локального
репозитория.

Задачи:

1. Полностью реализовать список методов перечисленных выше. [x]

2. Написать тесты для проверки верной работы класса Deq. [x]
