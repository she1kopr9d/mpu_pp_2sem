# Задание 3. Применение дека

## Формулировка задания

Напишите программу, которая с помощью дека определяет, является ли введенная
строка палиндромом.
Приведите примеры входных данных, на которых проверяли работоспособность
программы (не менее десяти).
Работа над решением должна сопровождаться полноценным ведением локального
репозитория.

ПОМЕТКА: Допустимо изменение типа хранимых в деке данных.
