# Задание 3. Применение дека

## Формулировка задания

Напишите программу, которая с помощью дека определяет, является ли введенная
строка палиндромом.
Приведите примеры входных данных, на которых проверяли работоспособность
программы (не менее десяти).
Работа над решением должна сопровождаться полноценным ведением локального
репозитория.

ПОМЕТКА: Допустимо изменение типа хранимых в деке данных.

Задачи:

1. Модифицировать Deq для возможности хранения данных разных типов. [x]

2. Написать программу, которая проверяет строку - палиндромом ли это. [x]

3. Написать тесты для проверки работоспособности программы. [x]

## Отчет по заданию

### Список проделанных действий

- Модифицировал Queue и Deq -> Queue<T> и Deq<T> для работы с разными типами данных (1).

- Написал функцию isPalindrome, которая проверяет "является ли строка палиндромом" (2).

- Написал генерацию Палиндромов и Не палиндромов.

- Реализовал тестирование функции isPalindrome через генерацию Палиндромов (3).
