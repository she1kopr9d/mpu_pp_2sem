# Задание 4. Применение односвязного списка

## Формулировка задания

Напишите программу, вводящую с клавиатуры (или из файла) последовательность
действий пользователя над приложениями (запуск приложения, переключение между
приложениями, закрытие приложения) и выводящую список приложений в порядке
востребованности (последнее активное приложение приоритетнее).

```
Пример ввода:
Run Mozilla Firefox
Run IntelliJ IDEA
Alt Tab +
Run UMLet
Alt Tab Tab + +
Alt Tab Tab Tab + + +
Alt Delete +
```

```
Вывод:
Mozilla Firefox
IntelliJ IDEA
Mozilla Firefox
UMLet
IntelliJ IDEA
IntelliJ IDEA
```

Приложения в операционной системе организованы в виде циклического списка и
упорядочены по убыванию времени последней активности. Приложение, окно которого
является активным в настоящий момент, – первое в списке, приложение, окно которого было
активно перед этим, – второе и т.д. Если нажать клавишу Alt и затем, не отпуская ее, нажать k
раз клавишу Tab, после чего отпустить клавишу Alt, то активным станет окно приложения,
которое находится на месте k n 1 % + в списке, где n – количество элементов в списке.
При решении задачи используйте реализацию класса L1List.
Приведите примеры входных данных, на которых проверяли работоспособность
программы (не менее десяти).
Работа над решением должна сопровождаться полноценным ведением локального
репозитория.

ПОМЕТКА: Допустимо изменение типа хранимых в списке данных.

## Отчет по заданию

### Описание функций, написанных в ходе решения данного задания

- size – подсчитывает количество элементов в списке.

- findIdByName – ищет ID приложения по его имени.

- moveToFrontById – перемещает элемент с заданным ID в голову списка.

- pushFront – вставляет новый ID в начало списка.

- popFront – удаляет голову списка и возвращает её ID.

- runCommand – обрабатывает команду Run: добавляет новое или перемещает существующее приложение в голову, выводит имя.

- deleteCommand – обрабатывает Alt Delete: удаляет голову и её запись из мапы (но в текущем коде не выводит имя).

- reChangePosition – обрабатывает Alt Tab: вычисляет позицию по формуле, перемещает выбранный элемент в голову и выводит его имя.

- execCommand – диспетчер, определяет тип команды и вызывает соответствующую функцию.

- splitCommands – разбивает строку по \n на массив команд.

- loadProgramFromFile – читает содержимое файла в строку.

- runProgram – принимает строку с командами и выполняет их.

- runTest – запускает тесты из файлов, выводит ввод и вывод для каждого.

### Список проделанных действий
