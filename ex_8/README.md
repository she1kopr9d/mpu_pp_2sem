# Задание 8. Реализация R3Vector

## Формулировка задания
Реализуйте класс R3Vector, описывающий радиус-вектор в трехмерном пространстве и
позволяющий выполнять следующие операции над векторами (объектами класса):

1. сложение двух векторов (как метод класса и как метод экземпляра класса); [x]

2. умножение вектора на число (как метод класса и как метод экземпляра класса); [x]

3. скалярное произведение двух векторов (как метод класса и как метод экземпляра
класса); [x]

4. векторное произведение двух векторов (как метод класса и как метод экземпляра
класса); [x]

5. сравнение двух векторов (как метод класса и как метод экземпляра класса). [x]

## Отчет по заданию

### Список проделанных действий

- Реализовал конструктор с доступными типами переменных: int; float; double.

- Реализовал сложение двух вектором (static и object версии) (1).

- Реализовал умножение вектора на число (static и object версии) (2).

- Реализовал скалярное произведение двух векторов (static и object версии) (3).

- Реализовал векторное произведение двух векторов (static и object версии) (4).

- Реализовал сравнение двух векторов (static и object версии) (5).
