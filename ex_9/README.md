# Задание 8. Реализация Matrix

## Формулировка задания
Реализуйте класс Matrix, описывающий матрицу и позволяющий выполнять
следующие операции над матрицами (объектами класса):

1. сложение двух матриц (как метод класса и как метод экземпляра класса); [x]

2. умножение матрицы на число (как метод класса и как метод экземпляра класса); [x]

3. умножение матрицы на матрицу (как метод класса и как метод экземпляра класса). [x]
