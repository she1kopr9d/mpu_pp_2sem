## Формулировка задания

```java
//Node.java
public class Node<T>{
    public T value;
    public Node<T> next;
    public Node(T value){
        this.value = value;
        next = null;
    }
}
```

```java
//L1List.java
public class L1List<T>{
    private Node<T> first, last; //Ссылки на первый и последний узлы.
    private int size;
    public L1List(){
        first = last = null;
        size = 0;
    }
    //Добавить элемент в конец списка.
    public void append(Node<T> node){
        node.next = null;
        if(first == null) //Первый элемент.
        first = node;
        if(last != null)
        last.next = node;
        last = node;
        size++;
    }
}
```
