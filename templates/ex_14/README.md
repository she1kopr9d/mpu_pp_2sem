# Задание 14. Использование словарей

## Формулировка задания

1. Проведите лексикографический анализ текста устава Московского Политеха (или
другого соизмеримого по объема текстового документа): получите данные о том,
какие слова в нем встречают и в каком количестве. Сохраните результаты в файле в п
орядке убывания частотности слов. [x]

(Выбранный мной файл - "КОНСТИТУЦИЯ РОССИЙСКОЙ ФЕДЕРАЦИИ". Ресурс, с которого получил текст http://kremlin.ru/acts/constitution/item)

2. Напишите программу, реализующую телефонный справочник для абонентов.
Предусмотрите возможность добавления новых абонентов , удаления абонентов,
поиска фамилии абонента по номеру его телефона. [ ]
